# URL Shortener
A URL shortener project created with Nestjs for Backend and Remix for frontend

## Prerequisite
- Nodejs 
- Code Editor (Vscode preferred)

## Running application
To run the full application follow the instruction below


--> Backend
- Open a terminal and cd into the backend folder, `cd backend`
- Then run `npm run start:dev`




--> Frontend
- Open a terminal and cd into the backend folder, `cd frontend`
- Then run `npm run dev`



## Running test

To run the API test
- - Open a terminal and cd into the backend folder, `cd backend`
- Then run `npm run test:e2e`
